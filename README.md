# EX No.5.2.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:18/11/2026

## AIM: 
To create a 3D model from given orthographic projection.
Detailed Explanation: The primary objective of this lab exercise is to convert 2D orthographic engineering drawings—such as the Front View, Top View, and Side View—into a complete, accurate 3D solid model using computer-aided design software.
Through this process, designers learn how to sketch 2D profiles based on structural blueprint and transform them into functional 3D parts using tools like extrusion.

## REQUIREMENTS: 
Autodesk Fusion 360: The core cloud-based Computer-Aided Design (CAD) software utilized for sketching, 3D modeling, and engineering design.
Windows 10: The minimum required operating system environment needed to run the Fusion 360 application smoothly and reliably.
16 GB of RAM: High-performance memory capacity required to handle complex 3D graphics and rendering operations (integrated graphics with 1 GB VRAM or more is strongly recommended).
Internet Connection: A stable broadband connection with a download speed of 2.5 Mbps or faster, and an upload speed of 500 Kbps or faster to support cloud saving and workspace syncing.

## PROCEDURE:

### STEP-1:
Open Autodesk Fusion 360 and Create a New File
1.Open Fusion 360: First, launch the Autodesk Fusion 360 application on your computer. Wait for the software to load completely and ensure you are signed into your Autodesk account if required.  
2.Select "File": Once the application interface opens, navigate to the top-left corner of the screen and click on the File menu (or the application menu button) to open the drop-down list of file options.  
3.Click "New File": From the drop-down menu, select the option to create a New File (often labeled as New Design). This opens up a fresh, blank workspace canvas where you can begin modeling your 2D sketch.

### STEP-2:
1.Select "Sketch" Option: Locate the toolbar at the top of the Fusion 360 workspace (under the Design tab) and find the Sketch menu or section.  
2.Choose "Create Sketch": Click on Create Sketch (typically represented by a green plus icon over a drawing grid).  
3.Select a Plane: After clicking Create Sketch, three origin planes (XY, XZ, and YZ) will appear in the center of your canvas. Click on the specific plane where you want to draw your 2D profile (for example, the bottom/top plane or front plane) to orient the camera flatly toward that surface so you can begin sketching.

### STEP-3: 
Create and Finalize the 2D Sketch
1. Create the Sketch Using Circle, Line, and Trim Operations: Use the 2D drawing tools in the Sketch toolbar—such as Line (to draw straight edges), Circle (to create circular features or holes), and Trim (to cut away unwanted overlapping lines)—to draw the exact shape shown in your reference figure. Make sure all corners are properly connected to form a closed profile.

2. Apply Finish Sketch: Once the 2D geometry and dimensions are complete, click the green checkmark labeled Finish Sketch in the top-right corner of the toolbar. This exits the 2D sketching environment and prepares the profile for 3D modeling.

### STEP-4:
Convert the 2D Sketch to a 3D Model
Use the Extrude Option: Go to the Create menu in the Solid tab and select Extrude (or press E on your keyboard). Click inside the closed 2D profile you just drew, then drag the directional arrow or type in the exact thickness/height value to pull the flat 2D sketch into a solid 3D object. Click OK to confirm.
<img width="750" height="711" alt="image" src="https://github.com/user-attachments/assets/5cd1c82e-c022-49a8-9b2f-29e1d54efe04" />

### STEP-5:
Switch to Drawing Mode
Switch from Design Mode to Drawing Mode: Click on the workspace switcher button in the top-left corner (currently showing Design). Hover over Drawing and select From Design. A dialog box will appear asking you to confirm the sheet size (e.g., A4 or A3) and standard (ISO/ASME); click OK to open a new 2D engineering drawing sheet (you will be prompted to save your 3D model first if you haven't already).
<img width="572" height="537" alt="image" src="https://github.com/user-attachments/assets/1ecc2e9f-0690-4040-a2d3-de0872713eaa" />
      
### STEP-6:
Generate Orthographic Projections
1. Select and Position the Base View: As soon as the drawing sheet opens, the Base View tool activates automatically (or you can select it from the top-left toolbar). Choose your primary orientation (such as Front or Top), adjust the scale if necessary, and click on the sheet to place your main reference view. Click OK to confirm the placement.  
2. Select the Projected View: Click on the Projected View tool in the toolbar, then click on the Base View you just placed. Move your cursor horizontally, vertically, and diagonally away from the base view and click to place the corresponding orthographic views (such as the Top view, Side view, and Isometric view). Press Enter or click the green checkmark to finish generating the projections.
